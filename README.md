## 🌍 Why Open Project Hub?

Thousands of interesting projects are built every day but never get discovered.

Open Project Hub gives builders a simple place to:

- 🚀 Showcase their projects
- 🌱 Share ideas and experiments
- 💻 Publish useful code
- 🤝 Find projects to contribute to
- 📚 Learn from other developers
- 🌍 Make projects accessible to everyone

## 🚀 How to Submit Your Project

### Option 1: Via GitHub Issues (Recommended)

1. Click on the [Issues](../../issues) tab
2. Click "New Issue"
3. Choose "📦 Project Submission"
4. Fill in your project details
5. Submit the issue

Our maintainers will review and help you add it to the hub.

### Option 2: Via Pull Request

1. **Fork** this repository
2. **Clone** your fork locally
3. **Create** a new folder under `projects/` with your project name:
   ```bash
   mkdir projects/my-awesome-project
   ```
4. **Add** your project files and a detailed `README.md`
5. **Update** `project-list.md` with your project details
6. **Commit** and push your changes
7. **Open** a Pull Request to this repository

**Project README should include:**
- Project name and description
- Technologies used
- Installation instructions (if applicable)
- Usage examples
- Screenshots/demos (if applicable)
- License information
- Your contact/attribution info

## 📋 Project Submission Guidelines

✅ **Do:**
- Include a clear README with your project
- Specify the license for your project
- Provide setup/installation instructions
- Add screenshots or demos if relevant
- Keep code organized and documented
- Be respectful and welcoming to others

❌ **Don't:**
- Submit malicious or harmful code
- Include sensitive data (API keys, passwords, etc.)
- Plagiarize or submit others' work without attribution
- Submit commercial/proprietary projects without clear licensing
- Include extremely large files (>100MB) - use Git LFS or external hosting
